# Instructor prep

Lecture-prep material for the instructor: handouts and reminders, each a LaTeX source with its compiled PDF.
One folder per lecture, named like the lecture directory under `docs/source/`.

This folder is outside `docs/source/`, so it is not published on the course site and nothing links to it. The
repository is public, though, so anything here can still be read on GitHub. Keep confidential notes, such as
unreleased exam questions or notes about students, somewhere private.

| Folder | Contents | Build |
|--------|----------|-------|
| `02-directed-acyclic-graphs/` | Four-page handout: cheat sheet, mind map, practice graphs, answers | `latexmk -pdf handout.tex` |
